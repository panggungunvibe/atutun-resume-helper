# 改简历 Skill

面向中文求职者的简历诊断与改写工作流。

1、用户：提供简历，格式不限（PDF、图片或文字均可）

2、AI：

（1）先读简历，判断校招／社招并提取意向岗位，只补问缺失信息及目标 JD；

（2）挖掘工作、校园和研究经历，按目标岗位判断可优化性；

（3）从招聘方角度重构项目目标、角色、行动和个人成果，给出诊断及 Word 简历。

## 1. 如何安装这个 Skill

把下面这句话直接发给你的 Agent：

> 帮我安装这个skill：[https://github.com/panggungunvibe/atutun-resume-helper](https://github.com/panggungunvibe/atutun-resume-helper)

Agent 会根据自己的 Skill 安装方式完成安装。

## 2. 这个 Skill 怎么用

### 第一步：上传自己的简历

向 Agent 上传需要修改的简历，可以是：

- PDF 简历；
- Word 简历；
- 简历截图或整理好的文字内容。

然后告诉它：

```text
帮我诊断并修改这份简历
```

### 第二步：补充缺失的求职信息

Agent 会先从简历及对话中判断招聘类型和求职意向，已有或能清楚判断的信息不会再问。只有不明确或存在冲突时才请你补充。

如果还不知道有没有目标 JD，Agent 会问一次。有的话发送职位截图、招聘链接或文字；明确没有的话，按照通用岗位要求诊断，不反复追问。

校招项目较少时，Agent 会从校园活动、社团、志愿服务或研究中挖掘可用项目，给具体回忆线索，帮助你补出真实负责范围、行动及成果。

### 第三步：获得诊断和最终版简历

Agent 会先在对话中告诉你：

1. 一份适合目标岗位的简历应该采用什么结构；
2. 你在每个结构下面目前存在什么问题；
3. 建议如何修改。

随后，它会基于以上分析生成一份修改后的 `.docx` 简历。Word 文件只保留最终简历正文，不会混入诊断过程和修改建议。

Agent 会按求职岗位关注的能力重新组织项目，而不是只润色原文。每段包含简洁背景、身份名词形式的角色、具体行动和与本人贡献相关的成果。指标根据项目目标选取，不统一堆工作量。

先挖掘所有经历后，若仍没有可以提取的真实项目，才停止改写并要求补充，不生成空壳 Word；已有行动与交付、仅缺数字时可先改写。

![简历诊断与最终 Word 产出示例](assets/resume-output-example.png)

简历中缺少但值得补充的信息会使用 `XXX` 占位，并通过黄色高亮或红色字体提醒。Skill 不会编造工作经历、项目数据或业务成果。
